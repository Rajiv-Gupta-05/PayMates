  1. Open backend/.env in your project

    SMTP_USER=yourname@gmail.com
  3. Go to myaccount.google.com/apppasswords and create an App Password
  4. Set SMTP_PASS to the 16-character password
    SMTP_PASS=abcd efgh ijkl mnop
  5. Restart the backend — emails will work instantly!
